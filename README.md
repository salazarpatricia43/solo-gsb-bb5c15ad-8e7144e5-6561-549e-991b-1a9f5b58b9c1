# 分支访谈脚本编辑器（Branch Interview Script Editor）

用 **Python FastAPI + SQLite + 原生 JavaScript** 构建的可视化分支访谈脚本编辑器。
在画布上创建问题节点、用条件选项连接成有向流程图，系统实时检测 **环路 / 孤立节点 / 未覆盖出口** 并在画布上标记；
保存后可进入「运行预览」按回答跳转并记录完整路径；支持脚本 JSON 导入导出与只读分享链接，
只读分享页支持凭**一次性续答令牌**暂停后恢复原会话继续作答。

## 一条命令启动

```bash
docker compose up -d --build
```

启动后打开浏览器访问：

- 编辑器主页（Web）： **http://localhost:8000**
- 只读分享页（Web）： http://localhost:8000/share.html?token=分享令牌
- API 文档（Swagger）： http://localhost:8000/docs （业务接口统一在 `http://localhost:8000/api/...`，端口均为 **8000**）

停止：`docker compose down`（数据保留在命名卷中；加 `-v` 可同时删除数据卷）。

> 首次启动会创建一张内置示例脚本（包含一条演示环路），方便立即体验校验标记。

## 端口与配置

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| 宿主机端口 | `8000` | 在 `docker-compose.yml` 的 `ports` 中修改，例如 `"9000:8000"` |
| `DB_PATH` | `/data/editor.db` | SQLite 数据库文件路径（容器内），已挂载到命名卷 `editor-data` 持久化 |
| 数据卷 | `editor-data` | 命名卷，容器删除后脚本、分享快照、作答会话与续答令牌仍保留 |
| 重启策略 | `unless-stopped` | 见 compose 文件 |

容器健康检查：每 30 秒请求一次 `GET /api/scripts`。

### 不用 Docker 的本地运行方式

需要 Python 3.11+：

```bash
pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 8000
# 此时数据库默认为项目根目录下的 editor.db；可用环境变量 DB_PATH 覆盖
```

本地运行的访问地址与端口同上：编辑器主页 http://localhost:8000 ，分享页 http://localhost:8000/share.html ，API 文档 http://localhost:8000/docs （基础路径 `/api/...`）。如需换端口，改 `uvicorn --port` 即可（容器部署则改 `docker-compose.yml` 的端口映射）。

## 功能说明

### 画布编辑

- **添加节点**：工具栏「＋ 添加问题节点」，节点支持「问题」和「告知」两种类型；
- **移动 / 平移**：拖动节点标题移动节点，在画布空白处拖动平移画布；
- **连线**：按住选项行右侧的小圆点（port）拖到目标节点松开，即建立「选中该选项 → 跳转目标节点」；
- **编辑**：点击节点在右侧属性栏修改标题、文案、选项文案与跳转目标，可标记「终止节点」和「起始节点」；
- 点击连线可修改跳转目标或删除连线。

### 撤销 / 重做

- 工具栏「↶ 撤销 / ↷ 重做」按钮与快捷键 **Ctrl/Cmd+Z**、**Shift+Ctrl/Cmd+Z**（另支持 Ctrl+Y）共用同一份历史；
- 覆盖节点增删、标题/文案/选项修改、连线增删与跳转目标修改、节点拖动等全部画布编辑；
- 一次节点拖动只记为一条历史；同一输入框内的连续输入自动合并为一条；
- 撤销/重做后画布、右侧属性栏与流程校验标记（环路/孤立/未覆盖出口）同步刷新，未保存徽标按当前内容与保存点的差异实时更新；
- 保存脚本或切换脚本后历史清空，从新的基线重新开始记录。

### 实时校验（客户端实时 + 保存后服务端复核）

| 标记 | 颜色 | 含义 |
| --- | --- | --- |
| 环路（cycle） | **红色** | 节点处于有向环中（Tarjan SCC 检测），可能导致访谈无法走到终点；对应连线也标红 |
| 孤立节点（orphan） | **橙色虚线** | 从起始节点出发不可达（BFS 不可达） |
| 未覆盖出口（uncovered） | **紫色** | 选项没有连接目标（紫色虚线连线/端口），或非终止节点没有任何选项 |

工具栏右侧实时显示各类问题的数量徽标；全部通过时显示「流程校验通过」。

### 运行预览与路径记录

- 保存后点击「▶ 运行预览」，从起始节点开始，按选项逐条跳转；
- 未连接目标的选项不可选；进入终止节点（或无选项节点）时显示「访谈结束」；
- 右侧实时记录完整 **回答路径**（节点顺序 + 每步选择的答案），可随时「重新开始」；
- 路径存储在服务端 SQLite（`runs` 表），刷新后仍可通过 `GET /api/runs/{id}` 查看。

### 分支覆盖统计

按**当前脚本**汇总已保存运行记录（编辑器「运行预览」与只读分享链接作答都会计入）中各选项被选择的次数，用于发现设计了但从未被受访者走到的分支：

- 工具栏「📊 分支覆盖」打开统计面板：运行会话数、已覆盖分支数、分支覆盖率、累计选择次数、走到结束的会话数，并按节点列出每个选项的选择次数条形图；红色行即「从未走过」的选项，点击任一行可直接跳转到对应节点；
- **节点属性区**：每个选项右侧带统计徽标 —— `✓ 已选 N 次` / `⚠ 从未走过 · 0 次`（红底标出）/ `— 未连接，不可选`；选项区下方给出本节点 `已走过 X/Y` 的小结；未选中任何节点时，属性栏底部显示整份脚本的覆盖概览；
- **脚本尚无运行记录时显示空统计**（提示去运行预览/分享，不标红任何选项），不会产生误导；
- 统计基于**上次保存**的脚本与 `runs` 表：刚新增、尚未保存的选项显示「新增 · 保存后统计」；有未保存改动时面板顶部给出提示。关闭运行预览弹窗、保存脚本或点击面板内「↻ 刷新统计」都会重新拉取；
- 未连接目标的选项在运行中不可选，只展示不纳入覆盖率；编辑脚本后已删除节点/选项的历史计数自动忽略；
- 覆盖统计是独立的只读查询，**不影响实时结构校验**（环路 / 孤立 / 未覆盖出口照常即时刷新）。

### 指定选项路线规划

- 工具栏「**🧭 路线规划**」打开规划面板：列出**当前画布**（含未保存修改）中全部已连接目标的选项，勾选 **1～6 个**后点击「开始规划」；
- 服务端以「当前节点 × 已收集勾选选项集合」为状态做 BFS，求从**起始节点**出发、**经过每个勾选选项至少一次**、最终到达**终止节点（含无选项节点）**的**最短选择序列**（以选择次数计）；
- 搜索**允许环路和重复访问节点**，但**标记为终止的节点不可继续选择**；若无可行路线会明确显示**无解**，不返回部分路径；
- 结果按顺序展示每一步的 **节点 → 所选选项 → 目标节点**，勾选选项带 ✓ 标记，终点单独标出；点击任一节点名可将该节点居中定位到画布并选中；
- 规划是只读计算（`POST /api/route-plan`，请求体即当前画布内容，不落库）：**不保存脚本、不生成运行记录、不改变分支覆盖统计**。

### 改稿影响分析

改稿后担心历史作答对不上新画布？工具栏「**🩺 改稿影响分析**」以**当前画布（含未保存修改）**为基准，对本脚本的**运行预览**与**只读分享作答**记录逐条重放核对：

- 服务端从**当前起点**出发，按答卷记录中的**历史选项顺序**逐步重放，逐步核对**跳转目标**，并只返回每个会话遇到的**首个断点**及原因；
- 识别的断点：**起点改变**（`start_changed`）、**节点消失**（`node_missing`）、**选项消失**（`option_missing`）、**跳转改指/改成未连接**（`redirected`）、**提前终止**（`early_terminal`，中途节点变成终点或没有选项）、**已结束答卷不再结束**（`ended_no_longer_terminal`）；
- **未完成答卷只核对已答部分**：暂停点之后的差异不判为受影响，暂停节点本身变成终点也算兼容；已答路径逐步完全匹配即标为**兼容**；
- 面板汇总**作答会话总数、兼容会话数、受影响会话数**（以及预览/分享来源分布与各断点原因数量）；展开任一条记录可查看完整历史路径，断点处高亮并可点击「🎯 定位断点节点」居中定位到画布（节点已删除时提示无法定位）；
- 每次打开面板或点击「↻ 重新分析当前画布」都会即时重放，因此不必先保存；分析期间画布又被改动时会提示结果可能已过期；
- 分析是**只读计算**（`POST /api/scripts/{id}/impact`，请求体即当前画布内容）：**不保存脚本、不改写作答记录、不改变分支覆盖统计**。

### JSON 导入 / 导出

- **导出**：下载形如 `脚本名.json` 的文件，格式为 `{"format":"branch-interview-script","version":1,"name":...,"content":...}`；
- **导入**：支持上述导出格式，也支持直接导入 `{"start_node_id":...,"nodes":[...]}` 的裸 content 对象；
- 内容经过 Pydantic 校验，格式非法时返回 400 与错误信息。

### 跨脚本移植分支

操作入口：编辑器工具栏「**🔀 跨脚本移植**」按钮（在「＋ 添加问题节点」与「↶ 撤销」之间）。在弹窗中：

1. 选择一份**当前脚本以外**的已保存脚本作为来源（来源列表来自 `GET /api/scripts`，脚本内容按需用 `GET /api/scripts/{id}` 拉取，不新增接口）；
2. 选择来源脚本中的**入口节点**（默认预选来源脚本的起始节点），面板实时显示将复制的节点数、内部连接数与未连接选项数；
3. 点击「移植到当前画布」，入口可达的节点与内部选项连接一次性复制到当前画布。

复制规则：

- 为每个节点、每个选项**重新生成 ID**，并统一重写复制范围内的内部跳转引用；原本无效、未连接，或指向复制范围之外的目标仍保持未连接（`target_id` 置空）；
- 使用带访问标记的广度优先遍历，**遇到环路或多条路径汇合时每个节点只复制一次**，内部选项连接也随节点各自复制一份；
- 新分支保持来源中的**相对坐标**，整体平移到**当前视野中心附近**（并限制在画布范围内），不覆盖原脚本内容，也**不改变当前脚本的起始节点**；
- 整次移植计为**一次撤销操作**（Ctrl/Cmd+Z 可整体撤回），移植完成后立即刷新未保存徽标与结构校验标记（环路 / 孤立 / 未覆盖出口）；移植内容尚未保存时不会出现在分支覆盖统计中，保存后即正常计入。

### 只读分享链接

- 工具栏「🔗 只读分享」生成形如 `http://localhost:8000/share.html?token=xxxx` 的链接；
- 分享内容是 **生成时的只读快照**（独立存储），之后继续编辑脚本不影响已分享版本；
- 分享页只展示受访者视角：逐题作答 + 路径记录，页面带「只读」提示，无任何编辑入口。

#### 暂停续答（一次性续答令牌）

受访者可以随时关掉页面、之后再接着答，而不必从头开始：

- **暂停**：作答过程中（任意**未结束**的题目节点）点击「⏸ 暂停并生成续答令牌」，弹窗中可复制
  - **一次性续答令牌**（一串随机字符串），以及
  - **含令牌的续答链接**（`share.html?token=分享令牌&resume=续答令牌`，重新打开即自动填好令牌）。
  令牌只在弹窗中显示一次，请立即复制保存；生成令牌**不会中断作答**，继续作答后再使用令牌会恢复到「使用令牌那一刻」的最新进度。
- **续答**：再次打开**同一个分享链接**，入口处选择「恢复会话」（或直接打开续答链接后确认），即可恢复**原来的会话、当前节点与完整回答路径**，继续作答；不会新建会话，右侧路径记录原样还原，页面顶部会显示恢复提示。
- **服务端约束**（错误信息会在入口处直接展示）：
  - 续答令牌与**所属分享快照**一一绑定，只能在该分享链接中使用，拿去别的分享链接会被拒绝；
  - 令牌**一次性**：恢复成功即刻作废，重复 / 并发再次使用都会返回「令牌已使用」；
  - **已结束**的访谈不能暂停、也不能续答（无需续答，可开始新的作答）；
  - 编辑器「▶ 运行预览」的会话不生成续答令牌（暂停续答仅面向只读分享受访者）。
- 「↺ 重新开始」仍是把**同一个会话**清空回到第一题（历史行为不变）；重新开始后，之前已使用 / 未使用的旧令牌都无法再恢复旧进度。

## 数据模型（SQLite）

- `scripts`：脚本（名称、JSON content、时间戳）；
- `shares`：只读分享快照（随机 token、快照内容）；
- `runs`：预览/分享作答会话（当前节点、步骤 JSON、是否结束）；分支覆盖统计即按脚本聚合该表中每步记录的 `node_id + option_id` 得到，无需额外建表；
- `resume_tokens`：暂停续答令牌（随机 token、所属 `run_id` 与 `share_token`、是否 `used` 一次性标记、时间戳）；令牌与分享快照绑定，恢复成功即原子置为已使用。

> 数据表均通过 `CREATE TABLE IF NOT EXISTS` 在启动时自动创建/补建，旧数据库升级到新版本后**无需手动迁移**，直接 `docker compose up -d --build` 即可。

## 主要 API

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/scripts` | 脚本列表 |
| POST | `/api/scripts` | 新建脚本 |
| GET/PUT/DELETE | `/api/scripts/{id}` | 读取 / 更新 / 删除 |
| POST | `/api/scripts/{id}/validate` | 服务端环路/孤立/未覆盖出口校验 |
| GET | `/api/scripts/{id}/coverage` | 分支覆盖统计：各选项被选择次数 / 从未走过的选项 / 覆盖率 |
| POST | `/api/scripts/{id}/impact` | 改稿影响分析：请求体为当前画布 content，逐条重放预览/分享作答，返回兼容数与受影响会话的首个断点（只读计算，不落库） |
| POST | `/api/route-plan` | 指定选项路线规划：请求体为当前画布 content + 1～6 个勾选选项，返回最短选择序列或无解（只读计算，不落库） |
| GET | `/api/scripts/{id}/export` | 导出 JSON |
| POST | `/api/import` | 导入 JSON |
| POST | `/api/scripts/{id}/share` | 生成只读分享链接 |
| GET | `/api/share/{token}` | 读取分享快照（read_only） |
| POST | `/api/runs` | 开始预览（`script_id` 或 `share_token`） |
| POST | `/api/runs/{id}/choice` | 提交一个选项并跳转 |
| GET | `/api/runs/{id}` | 查看会话与已记录路径 |
| POST | `/api/runs/{id}/restart` | 重新开始 |
| POST | `/api/runs/{id}/pause` | 仅分享作答会话可用：在当前未结束节点生成**一次性续答令牌**（已结束 / 编辑器预览返回 400） |
| POST | `/api/share/{token}/resume` | 用续答令牌恢复该分享快照下的原会话（原子消费令牌）；令牌不存在 404、属于其他分享 403、已使用 / 访谈已结束 400 |

## 目录结构

```
.
├── app/
│   ├── main.py        # FastAPI 路由：CRUD / 校验 / 路线规划 / 改稿影响分析 / 导入导出 / 分享 / 运行
│   ├── graph.py       # 图算法：Tarjan 环路、BFS 可达性、出口检查、路线规划、改稿重放核对、跳转
│   └── db.py          # SQLite 连接与建表
├── static/
│   ├── index.html     # 编辑器单页
│   ├── share.html     # 只读分享页
│   ├── app.js         # 编辑器：画布/连线/实时校验/预览/导入导出（原生 JS）
│   ├── common.js      # fetch/弹窗等公共函数
│   └── styles.css
├── Dockerfile
├── docker-compose.yml
└── requirements.txt
```
